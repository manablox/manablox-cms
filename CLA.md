**Pull requests.** Sign off each commit with the Developer Certificate of Origin
line, which `git commit -s` adds:

```

```

Use your real name and an address that reaches you. A signed-off commit in a
pull request against this repository is your acceptance of this agreement for
that Contribution.

someone authorised to bind the company should say so in the pull request, or
send a written confirmation to the Maintainer, before the first merge.

copy of this agreement instead of sign-off. That is a formality for the record,
with the same terms.
